# Assets

Place the following image files here before building:

| File                 | Size        | Purpose                            |
|----------------------|-------------|------------------------------------|
| `icon.png`           | 1024×1024   | App icon (iOS + Android)           |
| `splash.png`         | 1284×2778   | Splash/launch screen image         |
| `adaptive-icon.png`  | 1024×1024   | Android adaptive icon foreground   |
| `favicon.png`        | 48×48       | Web favicon (if using Expo Web)    |

**Quick start:** copy `public/fastget-logo.png` from the Next.js project,
resize it to 1024×1024 and save it as `icon.png` and `adaptive-icon.png`.
For `splash.png`, use a 1284×2778 canvas with `#1a56db` background and the
logo centred. The splash `resizeMode` is already set to `contain` in app.json.
